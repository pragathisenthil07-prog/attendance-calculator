#attendance Calculator
A simple Python program that takes a student's name, total classes and classes attended, then works out the attendance percentage and whether the student is eligible for exams.
What it does
Asks for the student's name
Takes total classes and classes attended
Calculates the attendance percentage
Shows "Eligible for exams" if attendance is 75% or more, otherwise "Attendance shortage"
How to run
Install Python 3
Download attendance_calculator.py
Run: python attendance_calculator.py
Enter the details when asked
Rule used
75% and above: Eligible for exams
Below 75%: Attendance shortage
